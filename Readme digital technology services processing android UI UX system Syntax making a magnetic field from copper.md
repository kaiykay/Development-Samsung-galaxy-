# Digital Technology Services - Android UI/UX System & Magnetic Field Generation

## Overview
This project integrates **digital technology services** with a focus on creating an **Android-based UI/UX system** designed to process and visualize the concept of **magnetic field generation using copper wire**. The system is built with interactive UI/UX design principles, enabling users to learn and experiment with the phenomenon of electromagnetism.

## Features
- **Android UI/UX Design**: Beautiful, responsive design tailored for mobile devices, offering an engaging learning experience on electromagnetism.
- **Magnetic Field Simulation**: Visualizes and simulates the creation of a magnetic field using copper wire, allowing users to interact with different parameters.
- **Educational Content**: Detailed tutorials, explanations, and guides on the principles of electromagnetism, focusing on copper wire and its interaction with electric current.
- **Real-Time Feedback**: Users can modify parameters like wire length, battery power, and coil density to see the effect on the generated magnetic field in real time.
- **Sensor Integration (Optional)**: Leverages Android device sensors (e.g., magnetometer) to detect real-world magnetic fields generated by physical setups.

## Supported Devices
- Android devices running **Android 5.0 (Lollipop)** or higher.
- Devices with **magnetometers** for real-world magnetic field detection (optional feature).
- Optimized for tablets and smartphones with responsive touch controls.

## Requirements
- **Android Studio**: Required for development and testing.
- **Kotlin/Java**: For backend development and logic.
- **Basic Knowledge of Electromagnetic Theory**: For understanding and explaining the physics involved in the app's educational content.

## How It Works: Magnetic Field from Copper
- **Magnetic Field Generation**: The app educates users on how a magnetic field is created when an electric current flows through copper wire. The magnetic field can be enhanced by wrapping the wire into a coil and using a ferromagnetic material (like a nail) as a core.
  
- **Interactive Simulation**: Users can adjust different parameters, such as wire coil count or battery power, and observe the impact on the magnetic field strength within the app.

- **Real-World Interaction**: If supported, the app utilizes the Android device’s magnetometer to provide real-time feedback based on the user's interactions with actual magnetic setups.
