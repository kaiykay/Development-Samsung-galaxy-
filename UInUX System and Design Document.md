## 2. UI/UX Principles

### 2.1 Design Philosophy
- **Simplicity** – Desain harus intuitif dan mudah digunakan.  
- **Consistency** – Penggunaan warna, ikon, dan elemen UI harus seragam.  
- **Accessibility** – Desain harus inklusif untuk semua pengguna.  

### 2.2 User Personas
| Nama | Usia | Pekerjaan | Kebutuhan | Tantangan |
|------|------|----------|-----------|-----------|
| Persona 1 | 25 | Mahasiswa | Navigasi cepat | Layar kecil |
| Persona 2 | 35 | Pengusaha | Dashboard bisnis | Kompleksitas data |

## 3. System Components

### 3.1 Design Tokens
- **Colors:** `#FF5733` (Primary), `#333333` (Text), `#F5F5F5` (Background)  
- **Typography:** Inter, Roboto, 14px/16px/24px  
- **Spacing & Grid:** 8px grid system  

### 3.2 UI Components
- **Buttons:** Primary, Secondary, Floating Action Button (FAB)  
- **Forms:** Input fields, checkboxes, radio buttons  
- **Navigation:** Sidebar, Bottom Navigation  
- **Cards & Modals:** Untuk tampilan konten interaktif
